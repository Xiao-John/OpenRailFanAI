# 03 · 旧版基线与新旧映射

> 用途：把"旧车次"翻译成"新车次"，以及判断一条旧数据在新体系里大概属于哪一类。
> 警告：**这里只有字头级映射**。逐趟车对照表官方尚未发布。

## 1. 2014 版基线

| 字头 | 旧含义 | 旧速度 | 旧读音 |
|---|---|---|---|
| G | 高速动车组 | 300–350 | 高 |
| D | 动车组（含动集） | 160–250 | 动 |
| C | 城际动车组 | 200–350 | 城 |
| S | 市郊列车 | ≤160（少量更高） | 市郊 |
| Z | 直达特快 | 160 | 直 |
| T | 特快 | 140 | 特 |
| K | 快速 | 120 | 快 |
| 无字头 | 普快 / 普慢 | ≤120 | — |
| L | 临时旅客列车 | — | — |
| Y | 旅游列车 | 120 | 游 |
| X | 行包 / 货运班列 | — | 行 |

旧号段（部分，C 级，仅帮助理解"号段紧张"）：

| 字头 | 号段 | 内部再分 |
|---|---|---|
| T | T1–T9998 | 直通图定 / 直通临客 / 管内临客 / 管内图定（[S14]） |
| K | K1–K9998 | 同上（[S14]） |
| Z | Z1–Z9998 | 直通 / 管内、图定 / 临客（[S14]） |
| Y | Y1–Y998 | 跨局 / 管内（[S14]） |

> 旧号段的具体切分不作为实现依据；只用来说明"总量看着够、实际可分配段不够"。

## 3. "A/推断"是什么意思

官方说法是"将现行 G、D 字头改为 G、T、K 字头"（[S3]），但**没有逐条点名**哪个速度段落到哪个字母。G→G、G(300)→T、D(200–250)→K 是由"G=350、T=300、K=200–250"的速度定义反推的，逻辑上唯一，但不是官方逐字表述。**实现时按此建表可以，对外引用时不要说是国铁原话。**

## 4. 语义漂移清单（最容易答错的点）

| 字头 | 旧 | 新 | 风险 |
|---|---|---|---|
| T | 特快 140（普速） | 动车组 300 | 用户说"我坐 T109"可能指旧车，也可能指新动车组 |
| K | 快速 120（普速） | 动车组 200–250 | "K 字头"从"绿皮"变成"动车"，且比 D 快 |
| X | 行包 / 货运班列 | 客运 >350 | 旧数据里的 X8001 是货车，新 X1 是最高档客车 |
| D | 动车组 160–250 | 动集 ≤200 | 旧 D 车次多数改 K，新 D 反而更慢 |
| Z | 读"直" | 读字母 /ziː/ | 语音/播报、TTS 需要改 |
| N/V | 旧 N 为管内快速（历史）；V 未用 | 新普速 140 / 120 | 旧语料里的 N 可能指历史车次 |

## 5. 映射的边界

- **不能**把"旧 G123"直接映射成"新 T456"：数字号段整体重排，官方会另行公布对照。
- **不能**假设"同一字母的新旧车次"是同一趟车：T/K/X 都发生了跨品类迁移。
- **可以**用字头级映射做：旧数据的粗分类、回答里的"原来的 T 现在叫 N"、迁移期的兜底解释。
- `折角/复车次`（一趟车中途换号，如 Z264/265）规则未变；新旧切换不改变上下行规则。
