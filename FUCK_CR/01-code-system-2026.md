# 01 · 2026 版车次编码体系

> 一句话：**用字头表达"速度等级 + 产品类别"**。客运 11 个字头，货运新增 B/DH，路用改 5 位数字 + DJ。
> 依据：2026 版《列车车次编排规定》官方解读（[S3]、[S4]）。规定全文未公开，本页是"解读级"规范。

## 1. 分类框架

官方口径（[S1]、[S3]）：

| 大类 | 字头 |
|---|---|
| 高速旅客列车 | **X、G、T、K** |
| 动集旅客列车 | D |
| 城际旅客列车 | C |
| 市郊（域）旅客列车 | S |
| 普速旅客列车 | Z、N、V |
| 普速旅游列车 | Y |

货运：班列 **B**、动车组快运 **DH**；路用：5 位纯数字 + **DJ**。

|---|---|---|---|---|---|

### 2.1 速度阶梯（注意不是字母序）

```
快  X  >350
    G  350
    T  300
    K  200–250      ← 比 D 快
    D  ≤200（动集）
    C  ≤200（城际，管内）
    S  ≤160（市域，管内）
    Z  160
    N  140
    V  120
慢
```

### 2.2 三个反直觉点

1. **K > D**：K 是 200–250 动车组，D 只剩 ≤200 的动集。字母在字母表里靠后，速度反而低。
2. **T/K 换了品类**：T/K 原来是普速"特快/快速"，现在是高速动车组；原来的 T/K 车次改挂 N/V。
3. **读音不统一**：X/G/T/K/D/C/S/Y 读汉字，Z/N/V 读字母音；"直"消失，"特/快"保留但指向动车组。

### 2.3 城际怎么命名

官方没有"高速城际"这个类别或字头。城际被**按速度拆进两类**（[S3]）：

| 城际类型 | 最高时速 | 新车次 | 说明 |
|---|---|---|---|
| 高速城际（如京津） | 350 | G | >200 的城际改挂 G/T/K |
| 高速城际（如沪宁） | 300 | T | 同上 |
| 城际动车组 | 200–250 | K | 同上 |
| 管内城际 | ≤200 | C | 唯一保留 C 的情形 |
| 跨局城际 | <200 | **未明确** | 官方未点名；C 限"管内"，不要自行归 C |

- 正式写法："城际动车组列车（>200 km/h，车次按速度挂 G/T/K）"；"高速城际"是口语，不是字头。
- `C` 的新含义是"**管内**城际（≤200）"，不等于"城际"全集。不要造"C 字头高速城际""G 城际"这类自定类别。
- 边界：200 km/h 同时落在 C（≤200 管内城际）与 K（200–250 动车组）的包含式定义里，官方用"城际铁路 + 管内"属性区分；跨局且 <200 的城际暂无归属，等细则/逐趟表。

## 4. 路用列车

- 轨道车、接触网作业车、大型养路机械、路内通勤、救援列车等：**5 位纯数字**，按数字段区分类型（[S3]）。
- 动车组检测/确认：`DJ`（读"动检"）+ 1–5 位数字（[S3]）。
- 动车组试运转：沿用 `X/G/T/K/D` + 55001–55998（[S14]，C 级，待官方条文）。

## 5. 编排权限与原则

- **车次唯一性**：同一时间一个车次只对应一趟列车（[S3]）。
- 客运车次：国铁集团本级统一编排（[S3]、[S7]）。
- 货运车次：跨局由国铁本级，管内由铁路局集团公司编排（[S3]、[S7]）。
- 跨境旅客列车境内段"结合实际相应调整"；临客使用同类产品字头 + 预留号段（[S3]）。

## 6. 官方为什么改

| 指标 | 2014 | 2025 | 增幅 |
|---|---|---|---|
| 营业里程 | 11.2 万 km | 16.5 万 km | +47.6% |
| 300–350 km/h 动车组 | 1018 标准组 | 3149 标准组 | +209% |
| 日均旅客列车 | 4894 列 | 11796 列 | +141.0% |
| 日均货物列车 | 18097 列 | 23571 列 | +30.2% |

- 高峰期 G 字头占可用号段 **90% 以上**，接近饱和（[S1]、[S3]、[S7]）。
- 目标："一看车次、便知产品"；分类清晰、层次分明（[S3]）。
- 扩容：动车组字头 4→7，可编排车次 +近 40%（[S1]、[S3]）。
- X 为更高速度等级预留，长江日报称主要为 CR450 留命名空间（[S10]，B 级）。
