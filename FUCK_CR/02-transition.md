# 02 · 时间线与过渡期

> 结论：**分两批、约一个月切换完**。第一批只动普速/旅游/货运/路用，第二批动高速/动集/城际/市郊/动车组快运。
> 过渡期最危险的不是"改号"，而是**同一列车在 15 天预售期内挂两个车次号**。

## 2. 两批范围

- **第一批**：普速旅客列车、普速旅游列车、因故折返旅客列车、特快班列；货物列车、军用列车、路用列车（不含动车组检测/确认/试运转）（[S3]、[S15]）。
- **第二批**：高速旅客列车、动集旅客列车、城际旅客列车、市郊（域）旅客列车、动车组快运列车；动车组检测/确认/试运转列车（[S3]、[S15]）。
- 第二批官方原话是"按照新的列车编排规定陆续组织开行 G、T、K、D、C、S 和 DH 字头列车"——**没有 X**（[S3]）。

## 3. 中间态：半新半旧

官方原则："**同一时间、同一字母仅表达一种含义**"（[S3]）。

由此推出 11/25–12 月下旬的窗口：

| 类别 | 这期间用什么 | 说明 |
|---|---|---|
| 普速 | 新：Z/N/V/Y | 原 T→N、原 K→V、无字头→V |
| 高速/动集/城际/市郊 | 旧：G/D/C/S | 尚未切换 |
| T、K | **营业客车里应无车** | 字母已腾空，等第二批 |
| X | 无客运车 | 旧 X 是货运，已改 B；新 X 未投用 |
| 货运 | 新：B/DH | 第一批已切 |

> "T/K 无车"是按分批口径的推断（C），不是官方原文。写代码时不要硬编码"T/K 一定不存在"，应以 12306 实际返回为准。

## 6. 服务连续性

新车次对应列车开行后（[S3]、[S6]）：

- 开行区段、运行时刻**按现行运行图执行**；后续调图才按新车次编图。
- 静音车厢、爱宠行、轻装行、自行车随身行、铁路畅行码、互联网订餐：标识方式、服务内容、产品体验**保持稳定**。
- 官方反复提示：核对车次、到发车站、运行时刻，以免误购误乘。

## 8. 过渡期软件陷阱

1. **双表达去重**：同一列车、不同日期、两个车次号。若按 `train_no` 去重，会被当成两趟车。
2. **字母语义漂移**：11/25 之后 `T`/`K` 在数据里暂时消失；12 月下旬再出现时含义已变。任何"按字母判断车型"的缓存都要带生效日期。
3. **旧号残留**：静态词典、GTFS、历史会话、旧截图里仍是旧号。回答要能说"这是同一趟车"。
4. **预售期边界**：查询日期跨过新车次开行日时，同一次查询可能返回两种号。
5. **X 的误判**：旧数据里 `X` 是货运班列（如中欧班列 X8001），新体系里 `X` 是最高档客运。**只按字母判断"X=货运"会错**。
