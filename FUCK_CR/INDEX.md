## 三条硬规矩

1. **不要编逐趟车对照表。** 官方只给了字头级规则；`G123 → T456` 这类映射现在只能是推算。
2. **不要把转述写成公告。** "11-24 18:00 / 11-25 00:00" 来自《上海铁道》报转述（S15），国铁公开口径只到"11 月下旬"。
3. **不要把 X 当成现有车次。** X 是给未来 >350 km/h 复兴号（CR450）预留的，第二批只开 G/T/K/D/C/S/DH，不开 X。

## 校验与维护

```bash
cd FUCK_CR && python3 check.py
# OK: JSON/CSV/引用/目录名/字头覆盖 全部一致（客运 11 个，映射 17 条，来源 16 条）
```

- 改任何文件前先读 [`06-maintenance.md`](06-maintenance.md)。
- 数据改动后同步 `01`/`03` 的表，跑 `check.py`，在 [`CHANGELOG.md`](CHANGELOG.md) 记一行。
- 官方新发布（规定全文、逐趟对照表、第二批日期）按 `06` 的触发表逐项更新。
