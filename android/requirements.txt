# Android 一体化版本的 Python 依赖清单（**全部纯 Python，无原生扩展**）
#
# 为什么是独立清单而不是复用 backend/requirements.txt：
#   1. Android 上没有 Rust 扩展的可用轮子，必须精确控制"装什么"；
#   2. 用 `options("--no-deps")` 安装，因此**这里必须列出完整闭包**
#      （不只是直接依赖）。闭包由 `pip install` 解析后 freeze 得出，
#      见 scripts/android/build.sh 顶部说明。
#   3. 服务端可以用 uvicorn[standard] 拿到 uvloop/httptools 加速，
#      Android 不行（同样没有轮子），所以两边清单必然不同。
#
# 版本：2026-09-15 由 pip 解析得到并锁定，避免上游大版本漂移导致构建日变。
# 升级时请本地重跑 backend/tests/run_all.sh 与真机构建后再改这里。

# 刻意**不安装**的包，以及为什么：
#
#   jiter            openai 的依赖，Rust 扩展，Android 无轮子。
#                    它只被 openai 流式助手的 `.parsed` 路径使用（两处 from_json，
#                    均由 `is_given(self._rich_response_format)` / tool_call strict 保护），
#                    本项目从不使用该路径。由 _android_compat 提供纯 Python 替身。
#
#   pydantic-settings  mcp-server-12306 的 utils/config.py 用它读 4 个环境变量，
#                    但它要求 pydantic>=2，与上面的 v1 冲突（这也正是必须用
#                    --no-deps 安装的原因）。由 _android_compat 提供替身。
#
#   mcp / mcp-types / opentelemetry-api / jsonschema / pyjwt / sse-starlette /
#   python-multipart / rpds-py  等 —— 都是 mcp-server-12306 声明的依赖，
#                    但只服务于"把 12306 当 MCP 服务器跑"那条链路。
#                    本项目只 import 它的 services/utils（纯业务代码），
#                    因此整条 MCP SDK 依赖链都可以不要。
#
#   uvloop / httptools / watchfiles / websockets  —— uvicorn[standard] 的加速件，非必需。
#   brotli          _http.py 里缺失会自动降级 gzip/deflate（代码已写明并测过）。
#   cryptography / cffi  —— 仅 MCP SDK 链路需要。
# ---------------------------------------------------------------------------
