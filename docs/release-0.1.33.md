# Main 0.1.33 · 图片复用与聊天交互修复

## 思考与滚动

- 修复流式思考区展开状态被重置的问题，可独立折叠；完成后遵循默认折叠偏好。
- 消息区同步上抬时，接近底部则滚至实际底部，确认后清除“回到底部”标记；等待布局更新，避免使用过期尺寸。
- 扩大跟随判定范围至约120dp，结合视口比例限制；离底阅读仍不强行跳转。

## 附件与重新生成

- 导入图片或文件后不再自动填入提问，不覆盖用户已有草稿。
- 附件保存到本机会话私有目录，以内容摘要校验；每条请求保存原提问、历史、附件引用、图片输入模式和思考设置。
- 重新生成和对应错误卡重试复用原请求附件与上下文，不使用当前新选的图片；会话及待发附件支持重启恢复。
- 文件缺失或损坏时明确提示，不发送替代输入。旧版未保存过原文件的附件历史仍需重新导入。
- 删除会话时取消活动请求并清除其附件；有引用的文件不按缓存过期，无引用文件经宽限期后清理。快照不保存API Key。

## 发布与检查

- 正式签名 Main ARM64 APK，包含离线词典及本地PaddleOCR模型，沿用原签名。
- Kotlin编译和静态差异检查通过；未做真机、模拟器及真实模型端到端验收。
