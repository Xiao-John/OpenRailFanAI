# Main 0.1.18 发布记录

日期：2026-10-05。此版使用当前共享工作区的Main Android客户端与已完成交接的Python后端。

## 本次内容

- 批量时刻查询逐趟展示完整结果卡片，保留成功摘要及失败项定向重试。
- 票价回执及席别/票价表格呈现为统一圆角卡片，无法完整识别的格式保留Markdown正文。
- 设置提供商使用选择层及编辑列表，枚举使用下拉，布尔项使用滑动开关；连接测试显示状态，未记住密钥时进程内仍能使用。
- 聊天引导、历史侧栏单行条目及紧凑操作菜单、统一输入框、透明回到底部浮层、统一功能图标及轻量动效。
- 所有回复支持复制、重新生成和分享；每条回复显示Token用量，会话累计独立保存。
- 后端按实际日期、车次和乘车区间查询时刻、余票、票价与交路；支持最多10车次、10日期的明确组合查询，保留部分失败结果和歧义澄清。
- 纯工具回执直接交付；未来交路不查询，普速担当说明数据源不支持；历史记录时间与图定时刻保持各自口径。

## 验证边界

后端回归及真实铁路接口采样由后端交接文档记录。0.1.17隔离模拟器曾确认G1时刻与重联担当、车组记录、单项时刻跳转及Token会话隔离；不能代替用户设备验证。

用户于10月5日停止模拟器调试。批量时刻明细和票价卡片通过Kotlin编译，本次执行Release打包及签名/版本/源码装包检查，不重新开展模拟器测试，不宣称完成新版端到端或视觉验收。
