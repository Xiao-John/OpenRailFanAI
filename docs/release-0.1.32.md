# Main 0.1.32 · PaddleOCR、续查与思考

## 本地图片识别

- Android 改用官方 PaddleOCR PP-OCRv5 mobile 检测和识别模型，由 ONNX Runtime 在设备本地运行；模型随包提供，无需识别时下载，不使用云端 OCR。
- 保留图片大小、像素、EXIF 方向、识别字数及取消限制，增加识别软时限和区域数量限制。
- 桌面后端提供同模型的可选 RapidOCR 适配，依赖见 backend/requirements-ocr.txt。
- 模型约20.5 MiB原始资源，正式包体积以本次资产为准。Android 使用轻量后处理，严重倾斜或弯曲文字效果仍待实测。

## 查询后可继续补查

- 检索失败、无记录或资料不足时，让模型读取已取得的事实和失败原因，选择下一项相关查询，每轮返回后再决策，最多四轮补查。
- 机位库未收录时，可补查目标车次的时刻等资料，再说明可确认内容及仍缺少的资料；无记录不等于停运，图定时刻不保证实际开行。
- 失败卡片保留，模型可以补充分析；规划失败不丢弃已有结果。原始未来日期、普速交路支持范围、乘车区间与数据时效限制继续生效。
- 简单且成功的结构化结果仍直接展示，避免额外等待。模型补查受轮次、输出预算、超时及重复请求限制。

## 思考与界面交互

- 输入框下方左侧新增默认关闭的“思考”滑块；设置页新增默认开启的“默认折叠思考内容”。
- 思考区与正文分开，可在生成中收起；实际返回内容按回复、会话隔离保存，停止或失败时保留已收到部分。
- 服务商不支持思考时兼容降级，不伪造思考内容；已有记忆隐私开关不变。
- 主页按钮范围内起手右滑也可打开侧栏，明确方向后取消按钮点击；降低滑动门槛，保留竖向与多指手势区分。
- 贴底状态下键盘或附件面板使内容上抬时，自动滚到最新内容底部；离底阅读保持原位，思考增量也纳入跟随。

## 发布与验证范围

- 正式签名 Main ARM64 APK，包含离线词典及 PaddleOCR 模型，沿用既有签名。
- Kotlin 编译、Python 语法和差异格式检查通过；本机后端已启动，健康响应正常。
- 未执行自动测试、真实图片推理、真实模型补查和真机验收；构建成功不代表上述功能完成端到端验收。
- 本轮未启用新车次解析器，LM 不增加 OCR 模型或运行库。
