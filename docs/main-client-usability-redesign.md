# Main 客户端交互修订（2026-10-03）

依据用户实机反馈重新设计，延续蓝色主操作、浅色卡片和圆角风格。系统状态栏、设备浮窗与手势条不属于应用界面。

## 设置

顶部固定返回、标题和保存；内容按云端模型、外观、系统操作分组。按钮至少48dp、同行等宽，长文本允许自然换行。

提供商入口打开独立卡片弹层，一次列出所有可用提供商和自定义入口。选择已有项保留密钥与模型配置；选择新项才添加。模型获取结果也以独立选择层呈现。高级参数默认收起。

连接测试按钮立即进入加载状态，结果在该按钮组下展示。处理中禁止重复测试、编辑配置和保存。失败提示不显示原始服务响应或密钥。

保存成功回到对话页；返回按应用导航栈返回。关闭“记住 API Key”只关闭磁盘持久化，密钥在当前进程中保留，跨仓储实例可用于请求；进程终止后需要重新填写。选择记住时继续使用既有加密存储。

## 对话与侧栏

顶栏左侧设置、历史，右侧新建。空对话显示欢迎说明和票价、时刻、交路、机位示例；点击示例先填草稿。

历史抽屉覆盖对话左侧，宽度约86%，保留右侧遮罩。搜索和新建固定顶部，今天/昨天/更早分组滚动，底部设置和帮助固定。会话选中后关闭抽屉；重命名、删除在独立确认层处理。

输入栏保持单一样式，阅读状态不会变换输入框或发送图标。只有生成时将发送按钮改为停止。输入栏按真实安全区及键盘适配。

滚动到底采用列表是否仍能继续向前滚动判定，支持末条消息高于整个视口。回到底部操作先滚到末项，再滚完末项的剩余内容；完成后隐藏提示。程序跟随更新不应被误判成用户上翻。

未来日期时刻卡不提供担当车组引导；后端检索和投机预取均不调用未来交路。显式未来交路查询说明担当尚无法提前确定，不展示交路查询失败。

历史主状态采集关闭菜单的侧栏，菜单操作另行自动采集到运行归档；不要求菜单打开时被遮挡的背景文字可见。关闭状态必须明确记录 `menu_state: closed` 且无菜单测量，旧版缺该字段仍按打开状态要求完整菜单证据，不以缺测冒充关闭。
