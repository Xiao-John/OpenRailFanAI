# Main 客户端补充修复

## 内容与错误

- 普通回答、流式回答和停止后保留的回答使用原生 Markdown 渲染，支持标题、强调、列表、引用、代码、链接及表格。宽表格可横向滚动。外部图片目前呈现替代文字和链接，不自动加载。
- Markdown 使用固定版本 CommonMark 0.24.0，许可保存在 third_party/licenses 及 Android raw 资源中。
- Android 内嵌 Python 缺少 IANA 时区数据库，原来的 Asia/Shanghai 查找会抛出 ZoneInfoNotFoundError。当前及未来铁路业务日期改用固定 UTC+8，不用于历史夏令时换算，不额外打包时区数据库。
- 明确的服务内部异常显示查询服务异常，查看详情不误导用户更换模型配置。

## 聊天与历史

- 回到底部浮层只绘制按钮自身背景，外围透明，不占列表高度；到达底部后隐藏。
- 历史条目单行显示；侧栏右上、右下圆角裁切。
- 重命名、删除菜单靠近所点条目定位，窄屏内限制边界；去掉重复标题和取消行，外部点击及系统返回关闭。删除仍须确认。
- 设置下拉选项增加圆角裁切，防止选中底色越界。

## 验证与限制

正式证据由 scripts/acceptance.sh 自动生成并归档到 acceptance/runs；最终状态查 acceptance/index.yaml 与 acceptance/_failed/index.yaml。
原生用例覆盖 Markdown 表格、链接、流式更新、嵌入 Python 日期、浮层高度及历史管理。真实外部铁路查询用例仍为显式启用项，跳过不代表端到端查询成功。
