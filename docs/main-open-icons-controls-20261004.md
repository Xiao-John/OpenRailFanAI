# Main 图标与选择控件修订

## 素材

核心品牌 Logo 保留。30 个功能图标采用固定版本 Lucide static 0.468.0，包括复制、重新生成、历史、搜索、删除、发送及状态图标；来源清单见 `third_party/licenses/lucide-icon-sources.json`。原始 SVG 保存于 Android raw 资源，转换后的矢量用于原生显示。许可文件随应用打包。

导入工具为 `scripts/icons/import_lucide.py`，支持路径、线段、折线、圆和圆角矩形；折线按坐标对转换，保留时钟指针等细节。停止按钮沿用实心符号，其他功能图标保持统一线条和主题颜色。没有引入完整图标库运行依赖。

## 操作

- 提供商卡片点击切换，绿色圆点表示当前项；右侧编辑独立展开配置，新增提供商仍通过独立选择弹层。
- 记住密钥改为滑动开关，整行可点击，滑块可拖动，忙碌时禁用；关闭仍仅影响持久化，当前进程可使用密钥。
- API 方言、主题展开选择列表，展示所有选项和当前项，不再循环切换。
- 主按钮、结果操作和追问按钮正文提高到16字号；辅助说明保持次级层级。
