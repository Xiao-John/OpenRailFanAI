## Token 计算约定

- 优先使用 `meta.usage.total_tokens`；缺少总量但输入、输出均返回时使用二者之和，不根据回答字数估算。
- 每条回复保存时累加一次，会话内重新生成的新请求也计入；界面重组、打开详情及会话切换不额外累加。
- 会话保留最多120条消息，独立累计字段 `totalTokens` 不因消息裁剪而减少；旧会话从仍保留的回复迁移。旧版本已裁剪掉的用量无法补算。
- 请求未返回用量的取消或失败不虚构消耗；累计仅代表已返回并保存的服务端用量，不等同于供应商账户完整账单。
- 回复操作、日期和来源语义、安全区及核心Logo保留既有约束。
