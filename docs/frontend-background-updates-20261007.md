# Main 软件与词典后台更新（2026-10-07）

## 修复范围

原软件下载接口先在 Python 后端完整下载 APK，再把文件返回 Android。客户端只能看到等待，无法反映公网下载进度。原设置页退出时还会取消软件及词典请求。

本轮改为应用级更新状态与 Android `dataSync` 前台服务。软件、词典各保留一个独立任务，重复点击不创建同类任务。离开设置页、进入聊天、切换应用或熄屏时，任务不再随页面销毁取消。

任务执行期间保留前台服务和有超时上限的 CPU 唤醒锁；任务全部结束后释放唤醒锁并停止服务。没有空闲时永久运行、开机启动或申请忽略省电限制的行为。系统强制停止应用、回收整个进程或限制后台执行仍可能中断任务，不能保证无限常驻。

## 显示与操作

- 软件：核对发布、下载、文件校验、安装包签名校验；下载阶段显示真实字节、总大小、百分比和耗时。
- 词典：沿用后端进度事件，显示下载、校验、导入、保存、确认本地版本等阶段；百分比只代表下载，不冒充整体导入完成度。
- 设置页恢复读取同一任务状态；页面生命周期不再取消网络连接。
- 通知栏显示各任务的阶段、下载字节及进度，各有取消入口；点通知打开设置并定位到对应更新区。
- Android 13 及以上首次开始更新时申请通知权限。拒绝通知不阻止更新，页面说明可回来查看进度。
- 词典取消后仍刷新本地版本，因为数据库提交可能已经完成；不会宣称取消等于数据回滚。
- APK 下载并验证成功后保留安装入口；后台不自动打开安装器。
- 私有存储保留已校验 APK 路径、版本及任务结束信息。进程重新启动时，未完成任务显示中断，清理 `.part` 文件；不会自动重放词典写入请求。
- 单次后台更新 30 分钟超时，网络连接另有超时限制；系统前台服务超时也会停止任务并保存提示。

## 软件下载链路与后端边界

软件发布检查仍调用本机后端 `/api/updates/software`。开始下载前再次检查版本及 SHA-256，使用既有响应中的 `asset.url`、`asset.size`、`asset.sha256`。

APK 字节改为 Android 直接下载公开发布附件，不再调用先完成整包下载的 `/api/updates/software/download`。仅接受目标仓库、目标版本与架构对应的 GitHub 安装包；只允许 HTTPS 和 GitHub 附件域名的有限次数跳转。限制声明大小、实际大小及 SHA-256，继续核对包名、升级版本和安装签名。

不携带 GitHub Token 或模型 API Key，也不在任务状态中保存这些凭据。本轮没有修改后端业务代码或更新接口。词典仍使用 `/api/updates/dictionary/apply/stream`，其后台服务与更新前台服务在同一个应用进程中运行。

Main 专用更新服务、安装权限、前台服务权限、通知权限及唤醒锁权限在 LM 构建的清单叠加中排除。

## 修改位置

- `UpdateTasks.kt`：应用级任务、状态、取消、结果持久化及中断恢复。
- `UpdateTaskService.kt`：前台通知、并行任务、后台生命周期及唤醒锁。
- `UpdateClient.kt`：公开 APK 下载、字节进度、地址/文件校验。
- `UpdateSettingsSection.kt`：任务状态展示、通知权限及更新区定位。
- `MainComposeActivity.kt`：通知返回设置。
- `MainSettingsScreen.kt`：允许更新卡片提供定位修饰符，不改变其他设置卡片样式。
- Android 清单与构建清单叠加：Main 服务和权限声明、LM 排除。

## 验证

验证记录保存在 `docs/verification/background-updates-20261007.json`，使用 Android 15 模拟器。

自动检查覆盖下载字节进度、文件校验失败、取消清理、声明大小不符、不受支持地址/跳转、词典旧字段兼容、更新区定位，以及真实前台服务在退出设置页和进入桌面后的继续执行。软件与词典同时运行时取消软件，词典仍继续，词典更新请求没有重复提交。

另外从真实 GitHub 公开发布附件接收字节后主动取消，只证明真实网络下载及取消清理，不作为完整安装成功证据。模拟器需临时使用宿主机已有网络代理才能访问 GitHub；测试后恢复其原配置。

功能验证完成后按用户要求发布 0.1.25；正式产物及发布状态见 [发布记录](release-0.1.25.md)。上述检查使用调试构建。更新组件没有独立设计原稿，本轮不把功能测试宣称为整套视觉验收完成。

## 后续实测

下一版发布后，用真机验证通知授权/拒绝、熄屏、切换应用、软件完整下载与系统安装，以及词典导入期间取消后重新读取版本。不同厂商的后台省电策略需分别确认。
