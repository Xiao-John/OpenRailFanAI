# Main 软件与词典更新接入

日期：2026-10-06。依据[软件更新与安装交接](backend-software-update-handoff-20261006.md)及[词典独立更新交接](backend-dictionary-update-handoff-20261006.md)。

## 客户端接入

设置页增加独立的软件更新、词典更新区。软件版本读取实际安装包，而不是后端源码版本。软件检查展示新版本、无法比较、无兼容安装包及请求失败反馈；更新说明可展开，发布页面限制为本项目。

安装包只通过本地后端下载；不显示虚假下载百分比。校验服务端散列、文件散列、应用包名、版本与签名，拒绝非更高版本。未完成或无效文件清理。安装通过系统安装器和受限 FileProvider；缺少未知来源安装权限时提示授权后再次安装，不把下载完成声称为安装成功。

词典独立读取本地版本、检查远端、导入 GTFS。取消导入时不声称回滚；提交阶段可能已完成，随后重新读取本地版本，保留手动刷新入口。更新范围为 GTFS，不把线路/车站档案缓存或其他资源声称为已更新。

请求仅访问本地服务，不内置 GitHub 凭证或模型密钥。离开设置页取消活动客户端请求。

## 正式版词典打包

Main release 默认携带 backend/data/dict.db，使用只读 SQLite 备份纳入已提交数据。LM 默认行为保持原状，更新安装入口权限和文件提供器在 LM 构建中排除。可使用 includeDict 显式覆盖；发布时应保持携带词典。

Main 启动时将随包词典原子解压到私有 bundled-dict/dict.db；DICT_BUNDLED_DB_PATH 指向随包副本，DICT_DB_PATH 指向独立运行数据库。解压不覆盖运行数据库，由后端负责版本合并和缓存保留。原始词典约13MB，APK压缩增量尚未测量。
