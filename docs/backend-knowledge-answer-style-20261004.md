# Main 闲聊与知识问答简答策略

日期：2026-10-04。针对“什么是重联”“只有同车型才可以重联在一起吗”的冗长回复。

## 已实施

仅修改 `backend/app/pipeline/generate.py`，为 Main 的 `question_type=knowledge` 选择独立作答策略。

- 简单问答默认 2—4 句、约 80—200 字，闲聊通常 1—2 句；这是提示目标，不是输出截断。
- 第一句回答问题，追问直接承接上文；用户要求详细说明、原理、对比或多个问题时可以展开。
- 取消检索过程开场、完整搜索结果条数播报、逐段免责声明、无关车型枚举与结尾邀请。
- 必要的来源、不确定性、冲突和失败仍如实说明；不编造参数或实时事实。检索确有截断且影响答案完整性时仍说明数量边界。
- 事实注入、来源及历史区块保留；Main 实时/混合问答、LM 提示、直接工具回执、生成预算、对外接口和前端均未改动。

## 验证与限制

修改前后比对 16 种提示组合（Main/LM × 精简开关 × 缺省/实时/混合/知识）：仅 Main 知识型两个组合变化；其余逐字节一致，事实、来源、历史标记出现次数一致。

当前源码的成本治理、票务交付、编排语义三个既有回归模块通过，变更空白检查通过。上述检查均离线执行，网络、私密文件访问和外部子进程拦截计数均为 0。

本轮未调用云端模型，也未测量实际回答字数、延迟或 token 降幅；不将提示目标当作模型实测效果。尚需用实际部署后端重试截图中的两轮提问。未重启共享服务或更新安装包。

增量补丁、修改前文件、哈希与验证记录独立保存在 `.ai/knowledge-answer-style/2026-10-04-v1/`，不覆盖此前事故维修归档。回退应只撤销 `style-only.patch` 的变更，保留原有票务维修及其他后续修改。
