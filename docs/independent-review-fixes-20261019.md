# 独立评审修复记录

依据：[独立评审复核版](independent-review-20261019.md)。本轮修复基于 `63583cc` 后的工作树，版本仍为 `0.1.29`，尚未重新打包或发布。

## 已落实

| 评审项 | 处理与边界 |
|---|---|
| B-1 现行解析截号 | 自由文本字头和纯数字车次都增加左边界；未知字头不再截成另一个车次，车组号连字符后的数字也不作为纯数字车次。保留正常英文问句中合法车次的识别，没有采用“英文开头就全部拒绝”的宽泛规则。没有引入任何新字头或新解释规则。 |
| H-1 空售票行 | 正常空响应返回带采样时间的空列表，让查询工具保留 `availability_status=empty`。非空但全坏的记录及传输失败继续报错。单项与批量都保留空结果元数据；批量正文和说明不再把正常空结果称为“查询失败”。 |
| H-4 测试入口 | 保留所有原套件，补登记原来遗漏的 8 套与本轮回归套件；默认 `--offline`，另有 `--live`、`--all`、`--list`。两个混合套件保留本地断言，只在离线模式跳过真实接口检查。Node 缺失或不能执行时明确跳过，支持 `NODE` 指定。完整通过、含跳过、环境跳过和失败分别汇总，不把断言错误当作环境跳过。固定公网抓取目标的 DNS 被映射至保留地址时显式跳过，SSRF 守卫保持不变。 |
| H-5 文档与版本 | 文档索引明确为精选；离线清单以测试入口为准；OpenAPI 元数据从根目录 `VERSION` 读取。`FUCK_CR` 内部资料留待新解析器工作处理。 |
| M-1 匿名部署 | 默认 CORS 仅同源，非回环 `HOST` 需要显式 `ALLOW_REMOTE_ACCESS=true`；启动时警告接口仍匿名，可消耗服务端模型密钥。增加 `METRICS_ENABLED`。这不是身份认证；命令行覆盖绑定地址的绕过边界、反代鉴权和可信网络要求已写入运行文档。 |
| M-2 描图资源 | 删除生产代码不再引用的 7 个描图属性，`NativeDesignPaths.kt` 从 1,511 行减至 136 行；实际图层构造从 1,464 个减至 110 个。保留的 `querySpinner` 完整属性字节一致，核心 Logo、原图、现用 Lucide 图标不变；生成脚本和来源记录同步收敛。没有据此宣称 APK 体积下降。 |
| M-3 隐性配置 | 售票行共享、Tesseract 路径及语言库路径进入 `Settings` 和 `.env.example`，运行中不再绕过配置缓存直接读这些环境变量。变更后须重启；回退开关保持可用。 |
| M-4 站名与网络边界 | 站名按原话位置、长度、名称稳定排序；保留被长站名包含的短名消歧。字典抓取把 HTTP/传输错误收敛为资料源不可用异常，里程工具返回 `ToolResult(ok=False)`，不把网络故障当成车站不存在，取消仍可传播。 |
| M-5 抓取预算 | 预算不足时不抓正文，先抓需要的条数，失败才补备用链接，预留来源开销。全部成功时不再额外抓两页后丢弃。 |
| M-5 请求摘要 | 请求内只序列化一次完整设置；供应商摘要仍随当前上下文隔离，不缓存额外的明文密钥副本；请求外沿用即时计算。 |
| M-5 软件更新 | 按版本倒序寻找当前架构有安装包的正式发布；最高版本缺包时可回退到可下载版本。存在但校验无效的包仍报错，不静默回退。所有版本都缺本架构安装包时不报告可更新，客户端给出缺包提示。 |
| M-5 来源链接 | 结构化时刻来源仅接受 `http(s)`；交路来源还校验真实 `rail.re` 域名边界。新增独立模块与前端回归。 |

测试修订保留检查意图：站名排序断言更新为明确的稳定规则；前端流式标记断言允许同一对象中增加其它字段；无时区子进程不再依赖启动目录；配置替身同步新增字段。没有把真实断言失败改成通过。

## 暂缓与责任边界

- 按用户指示，新解析器准备工作、改革语义/准入/过渡期、置信度结构及影子 `0X1` 等 H-2、H-3、M-4 改革项均未改动；B-1 属于现行输入安全修复。
- 离线中文 OCR 为已有明确产品要求，继续随包提供，不改为联网下载。R8/资源收缩尚未启用；Chaquopy、OCR 与动态加载的保留规则及安装后回归需要独立处理，不能仅为体积数字直接开启。
- LM 的 ML Kit 依赖耦合问题交由 LM 负责人处理，本轮未修改 LM 依赖策略或构建 LM 包。
- 目录体积复核约为 `.android-build` 18G、`dist/android` 2.6G、`acceptance` 488M、`.ai` 293M、`.git` 252M。没有删除历史 APK、词典、签名、工具链或验收证据，没有改写 Git 历史。旧产物需先归档到仓库外并校验后才能释放空间；当前未指定归档位置，因此清理尚未执行。
