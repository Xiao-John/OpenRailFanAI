# 所有助手回复的统一操作区

每条已保存助手回复底部统一展示复制、重新生成、分享。移除仅时刻卡片内出现操作区的条件，避免多张卡片重复操作栏。

- 普通回答复制/分享原始Markdown文本；结构化结果转换为可读文字，批量结果逐项拼接。
- 交路内容保留记录日期及“不是列车到发时间”的语义。
- 重新生成优先使用回复元数据里的原查询，旧会话缺字段时回溯最近一条用户消息。
- 分享通过Android ACTION_SEND和系统选择器，由用户选择目标，不直接发送。
- 分享图标为Lucide 0.468.0的share-2，来源登记在third_party/licenses/lucide-icon-sources.json，许可沿用既有ISC记录。
- 原生测试覆盖普通文字回复三项操作的实际回调与原提问对应关系，正式截图通过scripts/acceptance.sh生成。

## 本轮补充

加载提示区分理解、检索及生成阶段，不再固定称为列车数据；加载和流式回答共用带头像的回复行，并使用轻量展开及尺寸过渡。加载卡宽度对齐普通回复区。
历史单行条目改为48dp最小高度，标题垂直居中；右侧更多按钮保持48dp。

新建入口共用保护逻辑：当前空白会话重复点击显示“已在新对话中”；从已有会话新建时，优先复用已存在的待用空白会话。复用时恢复草稿，不清空未发送文字，不删除旧会话。持久化用例覆盖连续点击及从有内容会话切回待用会话。

统一操作区增加后，交路记录行统一为64dp，批量操作前后间距各8个设计单位；保持完整记录及触控区域，让首屏更紧凑，避免自动滚动后提示气泡被切断。
