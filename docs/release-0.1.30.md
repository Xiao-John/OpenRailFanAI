# Main 0.1.30 · 个人记忆与统一侧栏

## 个人记忆（试用）

- 新增本机跨对话记忆库，默认关闭，可在设置或侧栏“记忆”中开启、管理、逐条删除和清空。
- 用户消息、助手回复均有“记忆”入口，编辑并确认后才保存；窄屏纯图标，宽屏图标加文字，支持无障碍名称。
- 只保存明确选定的内容，也支持“记住：内容”；不自动收集全部聊天。
- 开启后，相关记忆可能随提问发送给当前服务商。“查看记忆总结”经确认后重新读取本机全部记忆，由当前模型总结，不使用旧总结冒充，不覆盖原始记录。
- 关闭停止后续跨对话记忆使用，不删除原记录、当前对话历史，也不能撤回已经发出的内容。应用卸载会移除本机记忆；目前不提供云同步。

## 界面与交互

- 主页合并为一个侧栏入口，右侧保留新建；侧栏上方仅记忆，下方为对话，底部设置固定。
- 主页右滑打开侧栏，侧栏左滑关闭；遮罩和返回键也可关闭，已被子控件消费的拖动不接管。
- 首轮正常回复后由模型概括会话标题，保留手动命名；失败保持未命名，不用第一句话假冒总结。标题调用的已报告 Token 计入对应会话。
- 附件导入改为输入框下方上推工具区，提供拍照、相册、文件；沿用统一开放图标，保留草稿、大小限制与显式发送。
- 首页交路示例修正为 CR400BF-5033，Android 与 WebUI 同步。

## 查询与可靠性修复

- 修复未知车次字头被截成另一趟车的现行解析缺陷，没有启用新车次改革规则。
- 修复正常空售票响应被显示为接口失败；批量回执保留空结果及采样时间。
- 站名排序稳定化，字典网络异常与资料缺失区分；正文预算不足不再无效抓取，按需补抓备用页面。
- 更新选择回退到当前架构最新可下载版本，继续保留签名、摘要与来源校验；来源链接统一过滤网页协议。
- 默认 CORS 仅同源，非回环 HOST 须明确确认匿名部署风险，指标接口可关闭；配置与文档同步。
- 删除未使用的旧描图资源，保留现用图形及核心 Logo；完整包继续包含离线词典和中文 OCR。
