# 云端 API 性能基线（2026-09-25）

本次基线使用当前配置的真实 OpenAI 兼容云端供应商，通过 `/api/chat/stream` 对同一组 5 条问句各请求 3 次。15/15 请求正常完成，无降级、错误或截断。问句逐轮串行执行，轮间等待 1 秒；后续轮次会命中进程内数据缓存，因此检索耗时同时反映冷/热缓存情况。

## 结果

| 场景 | 端到端中位数 | 决策中位数 | 检索中位数 | 生成阶段估算中位数 | prompt tokens 中位数 | completion tokens 中位数 |
|---|---:|---:|---:|---:|---:|---:|
| 动车组担当：`G1今天由哪组动车组担当？` | 6.91 s | 2.8 ms | 234 ms | 6.68 s | 1,837 | 278 |
| 余票：`明天北京到上海的高铁还有票吗？` | 10.68 s | 2.3 ms | 441 ms | 10.30 s | 2,093 | 852 |
| 车站大屏：`北京南站大屏今天下午有哪些高铁？` | 16.41 s | 3.4 ms | 16 ms | 15.37 s | 2,571 | 740 |
| 知识问答：`CR400AF 为什么叫复兴号？` | 16.26 s | 1.96 s | 398 ms | 14.73 s | 5,085 | 482 |
| 拍摄点：`吉林市XX区，要拍 CR400AF，今天下午` | 9.85 s | 2.4 ms | 943 ms | 8.40 s | 3,616 | 661 |

生成阶段估算 = 客户端端到端时间 − 决策阶段时间 − 检索阶段时间，包含生成请求及流式传输开销。15 轮累计返回 54,972 tokens；这是 API usage 汇总，不等同于费用，具体费用取决于供应商价格和 token 分类。

## 观察

- 本组实时型问句的确定性决策只需约 2–3 ms；知识问句需一次结构化云端决策，耗时约 1–2.5 s。
- 生成阶段占端到端时间主体，约 6.7–15.4 s。优先优化方向是生成模型/供应商首 token 与输出速度、生成提示词长度及不必要的长答，而非本地编排开销。
- 大屏检索从首次 2.08 s 降至缓存命中约 16 ms，但端到端仍约 15–18 s，说明进一步缓存检索对这条路径的整体收益有限。
- 端到端时间范围为 6.03–21.18 s，云端推理和网络波动明显；每类仅 3 次，当前只作为起始基线，不用于供应商排名或 SLA 判断。
