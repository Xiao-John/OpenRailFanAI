# Main 0.1.19 发布记录

日期：2026-10-06。包名 org.openrailfanai.app；版本名称0.1.19，版本号119；Main arm64 Release。

## 本次内容

- 接入版本1结构化票价结果；多车次、多日期混合结果保留独立归属。
- 票价卡片区分实际执行票价与公布参考票价，旧历史回复不按新默认规则重新解释。
- 票价卡片增加区间、日期/历时、接口到发时刻、席别金额、说明及来源详情分区；复制和分享保留完整口径。
- 后端实际执行票价改用售票查询绑定，失败不回退公布价；明确公布价查询仅使用有有效来源与适用期的本地资料。当前随包库尚无公布票价数据覆盖，不声称能回答全路参考价。
- 设置页增加软件检查、校验下载、系统安装入口，以及独立GTFS词典检查/导入。
- 正式版随包词典独立解压，运行数据库交由后端按版本合并；GTFS更新保留档案与公布价表。
- 安装图标采用现有列车品牌Logo，补齐Android自适应图标与旧系统矢量图标。
