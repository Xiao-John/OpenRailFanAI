# Main 个人记忆库试用版

日期：2026-10-21。本轮实现 Android Main 的本机记忆库与后端无状态模型总结，不依赖某家供应商的账户记忆，不接入新车次解析器。

## 用户入口

设置页新增“个人记忆”：

- “启用跨对话记忆”滑块默认关闭，开关立即生效，不依赖页面顶部再次保存。
- 可以手工添加明确记忆，展开管理原始记录、逐条删除或确认清空。
- “查看记忆总结”是独立操作。用户确认将记忆发给当前已保存的模型后，客户端重新读取当前文件快照，由当前模型生成总结。不是显示全部记录，也不是读取旧的总结缓存。
- 总结不写回记忆文件；退出页面、关闭开关、删除或清空记忆会使当前总结失效。

输入消息与助手回复的操作区均新增“记忆”。小屏同一规则显示纯图标，宽屏显示图标加文字；保留操作名称的无障碍语义与 44dp 触控下限。点击后预览、编辑并确认保存；助手回复明确标记为未经独立核实的历史资料。用户消息同时提供“修改”入口，仅填回草稿，不直接发送。

也可单独发送 `记住：内容` 或 `请记住：内容`。该命令由设备处理，不调用模型；关闭记忆时拒绝保存并提示去设置开启。此阶段不自动从其它聊天或模型输出中提取记忆。

## 存储与检索

- Android 应用私有目录 `personal-memory.json`，通过 AtomicFile 写入，结构为 `schema_version=1` 与 `records` 数组。
- 每条包含 `id`、`text`、`source`、`saved_at`。最多 64 条、每条 2000 字、正文总量 32000 字；超限明确拒绝，不静默截断。重复正文不重复保存。
- 常见 API Key / GitHub 令牌形式禁止保存；仍不应主动把密码、凭据等写入记忆。
- 开启后，每次普通提问按文本相关性与新近顺序选择片段，最多 8 条、合计 4000 字（含来源时间）放入可选 `personal_memory` 字段。没有相关匹配时以近期记录补充背景；这不是向量语义检索。
- 后端仅在生成层使用这些资料，不用于决定铁路工具参数，不作为系统指令或实时运行事实。确定性铁路卡片继续由工具结果生成。
- 文件处理请求也可接收用户选定的个人背景，但不能据此生成文件系统访问权限。
- 记忆读取失败时，本轮退回不附带记忆的普通对话，并在客户端提示；损坏文件不会被当作空库自动覆盖。

## 模型总结接口

`POST /api/memory/summary`：沿用当前对话供应商、模型、API 方言和凭据覆盖字段，另带重新读取的全部 `records` 正文及来源时间。后端不接受任意文件路径、不读取服务器个人文件、不落盘。

请求中每条记录上限 2100 字（为正文加来源时间留余量），最多 64 条。根据当前模型窗口预估完整输入预算；不足时拒绝，不截掉一部分后声称总结了全部。模型没有输出、输出被截断或服务不可用时，不展示为完整总结。客户端核对返回的记录数量，失败时保留原记忆。

处于 LLM_MOCK 演示模式时拒绝生成“真实模型总结”，不把演示回复冒充读取结果。取消操作断开客户端请求；已发送的内容无法撤回，也不承诺上游一定立即停止计费。

## 隐私边界

- 开关关闭：不新增记忆，不向后续对话或总结请求附带记忆。已有记忆保留，仍可在本机管理或清空。
- 关闭只影响跨对话记忆；当前会话历史仍按正常聊天规则使用。删除记忆不等于删除聊天记录或撤回服务商已经接收的内容。
- 开启意味着相关片段可能随问题发给用户选定的服务商。“生成总结”经用户单独确认后发送当前全部记忆；密钥仅用于认证，不作为总结资料。
- 本机文件依赖 Android 应用沙箱保护，未宣称额外文件加密。不导出到模型设置文件；应用既有 `allowBackup=false` 保持不变。
- 本轮不增加后台自动提炼、后台模型请求、云同步、长期任务调度或服务器公共记忆库。不同客户端的内容只在各自请求中传入，不共享文件或全局上下文。

## 当前验证范围

Python 源码编译、Kotlin 主代码及原生测试源码编译检查见本轮构建日志。未新增或执行自动化测试，未使用真实 Key 调用总结模型，未完成真机交互/视觉验收，不生成正式通过图片。版本号未递增，未打包或上传 APK。

建议实测：关闭时分别点击两侧记忆入口；开启后保存一条偏好并切换对话；生成总结时确认当前模型；取消、关闭、重新开启后检查旧总结不回显；逐条删除、清空及重启后核对状态。
