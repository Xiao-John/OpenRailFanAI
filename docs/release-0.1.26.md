# Main 0.1.26 发布记录

日期：2026-10-09。包名 `org.openrailfanai.app`，版本名称 0.1.26、版本号126；Main arm64 Release，沿用原正式签名。

## 更新

- 机位查询新增与时刻、票价卡片统一的原生机位卡片，区分名称、已确认字段、条件组和来源。
- 默认只显示一个“待确认”入口；点击后读取说明，区分本机位与整篇攻略问题，原文依据折叠显示。
- 说明支持局部加载、重试和索引更新提示；关闭后保留原回答、草稿和阅读状态。
- 旧词典、未复核及原文变化保持兼容；不将未确认铁路、开放许可或缺失字段当成确定事实。
- 卡片随回复保存，复制和分享包含已展示的机位字段及来源；说明详情每次打开检查最新索引，不长期缓存。
- 包含后端交接的只读机位标注接口与完整词典；沿用既有软件、词典后台更新功能。

## 初步验证

Android 15 模拟器5项专项检查通过：默认卡片及按需加载、关闭后草稿、说明更新与重试、旧词典/未复核/原文变化兼容、真实后端词典接口、历史回复卡片与复制。部分行为在同一检查中覆盖。新入口触控高度至少44dp。

默认卡片的自动设计对照由 `scripts/acceptance.sh --photo-cards` 生成；协调性审核与功能检查仅代表本次新增模块的初步验证，不等于整机、全部界面或云端模型完整验收。详细索引见 `acceptance/index.yaml`；失败及未测记录保持原状态。

当前卡片基于既有 SSE 地点槽位读取已确认线索；不能推断模型正文中的未提供字段。没有地点或没有已确认结构化结果时，保留文字回复及可用来源说明。不把展示的前三处当成全部结果。
