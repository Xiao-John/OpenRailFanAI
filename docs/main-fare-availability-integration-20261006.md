# Main 票价与余票合并卡片接入

日期：2026-10-06。依据[后端交接](backend-fare-availability-handoff-20261006.md)。

## 客户端已落实

- 版本1 ticket_fare 解析 fare_status、fare_error 与 availability，旧回执无新增字段时沿用原票价状态和两列表格。旧历史不显示虚构余票状态。
- 合并卡片标题为“票价与余票”，表格按归一化席别名称取并集，显示席别/票价/余票；不按下标关联、不跨车次日期或区间合并。
- 单项分别判断状态：金额完整性使用 fare_status；票价失败仍保留余票，余票失败仍保留票价。未查询、空记录、失败、信息不完整分别提示。
- 有票或原始张数、无票、候补、未提供分别显示；候补使用独立暖色，未知不解释成无票。票价可作为购票参考；余票为查询时快照，不保证购票时仍然有票。
- 查询详情分别保留两项来源、UTC采样时刻与接口时刻；冲突明确提示并保留两份原值。票价不可用而余票接口有时刻时，在卡片显示带来源口径的余票时刻块。
- 重开历史继续从原始结构化JSON解析；复制/分享包含两项状态、席别并集、来源、各自采样时刻、错误与冲突说明。
- 合并回执正文暂不去重：只有旧纯票价回执继续按完整事实匹配去重。不能证明两项结构化事实同时对应时，保留原文，避免误删余票或说明。
- 新增字段格式无效时降级原始正文，不吞掉尚未识别的数据。
