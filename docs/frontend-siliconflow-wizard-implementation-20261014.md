# 硅基流动配置向导：首批实现

2026-10-19 更新：向导已抽为 `ProviderSetupWizard.kt` / `ProviderSetupProgress.kt`，扩展到其他云端预设；新的实现与验证状态见 `frontend-multi-provider-wizard-20261019.md`。下文为首批硅基流动接入记录。

日期：2026-10-14。Main Android，Kotlin / Compose。

## 完成内容

设置页新增“硅基流动配置向导”，未完成时显示继续入口；官方硅基流动配置编辑中的帮助按钮也进入向导。

七步独立弹层：使用硅基流动、注册登录、实名认证、确认额度、创建密钥、粘贴连接、配置完成。每一步有明确说明和官方直达地址；已有密钥可直接连接，已有额度可跳过充值。向导不会申请支付、签约自动充值或读取登录账户信息。

步骤推进由用户明确确认；从浏览器切回不自动推进。当前步骤和模型选择保存到本机，官网跳转前及“稍后继续”会保存。模型与连接地址来自既有官方预设，不覆盖已配置模型。预设暂未加载时可先阅读官网步骤，连接前要求加载成功；不会把官方密钥发送给改过域名的配置。

模型为空时读取账户对话模型，优先选择可用的既定候选；多模型列表没有候选时提示用户选择，不随机切换未知型号。点击连接才发送真实测试请求；验证成功后保存、激活配置，完成卡片返回原对话。取消期间不保存迟到的验证结果。

## 密钥与进度

步骤状态为不引用Android.*的 `SiliconSetupProgress.kt`，Compose界面为 `SiliconSetupWizard.kt`。

进度字段只包含step、rememberKey、model，不包含密钥。服务商条目可用remember_key单独记录保存选择，旧条目继续读取原rememberKey默认值；向导保存只更新硅基流动配置，不修改其他账户密钥或保存选择。凭据由既有MainSettingsRepository管理：选择记住时可加密保存向导草稿；关闭时仅保存在当前进程，进程被回收后需要重新输入。未完成向导不会持久化启用新提供商，也不删除或更改其他提供商。

完成后清理向导专用进度及凭据，正常配置继续按保存选项保管。保存失败留在卡片重试；已成功保存后的进度清理失败不撤销可用配置。

## 官网窗口接入

硅基流动向导的官网入口使用 Android Custom Tabs，采用当前应用的明暗配色并显示网站标题；关闭官网窗口后回到向导。跳转前继续保存步骤，返回不会自动判定登录、实名或付款成功。仅允许硅基流动官方 HTTPS 域名。

设备没有支持 Custom Tabs 的浏览器，或所选浏览器组件不可用时，回退到普通浏览器。没有可用浏览器时由向导显示打开失败提示。普通设置帮助链接保持原有打开方式。

登录、验证码和付款均由官方网页与浏览器处理；应用不读取网页、Cookie、账号密码或登录状态。没有加入商业授权或自动取得 API Key 的接口。

Custom Tabs 接入后的 `compileDebugKotlin` 成功，源码差异格式检查通过。尚未在手机验证浏览器关闭返回、短信登录或支付回跳。

后续链接修订：向导跳转统一声明 `locale=zh-CN` 与 `Accept-Language: zh-CN`；密钥管理改为 `/me/account/ak`，首次打开及重新打开使用相同地址。未登录请求的公开重定向进入 `/zh/login` 并保留密钥管理目标地址；登录后的页面语言仍需真机确认。

对话结构化卡片的数据来源、机位来源及 Markdown 网页链接统一接入同一 Custom Tabs 打开器，保留普通浏览器回退。此修订不改变后端返回内容或登录状态判断。

## 当前验证与边界

`compileDebugKotlin`成功；相关源码差异格式检查通过。本轮未执行UI自动化、真实账户连接、注册、实名或付款；未生成APK或正式验收图片。不能将编译成功视为“零搜索”验收通过。

未登录的公共官方资料已在设计阶段核对；登录后的移动官网、手机支付回跳、长模型名、大字体、键盘与后台恢复仍需实际检查。其他服务商仅保留原有预设编辑，本次不扩展向导。
