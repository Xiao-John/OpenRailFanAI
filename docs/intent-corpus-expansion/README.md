# 意图语料与内部分类：分发包

日期：2026-10-01。这里是可分发提示词，不是已生成语料，也没有修改运行代码。

需要扩增的是独立语义样本、边界对照和上下文证据；细化的是内部操作分类。当前八个对外 Intent 保持不变。已有 192 条冻结意图语料适合检查回归，但 `either` 的检查较弱，不能承担完整准确率评测。

## 如何分发

每个 agent 收到一份对应的 `prompt-*.md`，并能读取同目录 [CONTRACT.md](CONTRACT.md)。没有仓库访问时，将两份文件一起提供。提示词已经包含读取范围和写入范围，不需要让 agent 阅读整个项目。

| 顺序 | 提示词 | 任务 | 首批规模 |
| --- | --- | --- | --- |
| 并行 A | [01 分类建构](prompt-01-taxonomy.md) | 操作定义、边界、八个 Intent 映射、能力缺口 | 分类候选及至少 30 组边界对照 |
| 并行 S | [02 单轮语料](prompt-02-single-turn.md) | 明确业务诉求、自然说法、槽位与过滤条件 | 100 条候选 |
| 并行 M | [03 多轮与时间](prompt-03-context-time.md) | 历史来源、换对象、换日期、时段及冲突 | 100 条候选 |
| 并行 C | [04 冲突与反例](prompt-04-conflicts.md) | 多诉求、误接管、实体串类、非铁路边界 | 100 条候选 |
| 生成后 B | [05 独立标注](prompt-05-blind-label.md) | 新上下文、只看 inputs，不看生成者标签 | 对 300 条独立标注 |
| 标注后 R | [06 复核裁决](prompt-06-review.md) | 比较两份标注，记录争议，提出可确认语料 | 全量复核，疑难项留待人工 |
| 独立 H | [07 保留集](prompt-07-holdout.md) | 独立生成未用于补规则的评测样本 | 80 条候选，不进入开发池 |

A/S/M/C 可以同时开展：所有语料先按统一契约的暂定操作表标注。A 只能提出分类变更建议，不直接修改契约或让其他 agent 临时改标签。待统一裁决后再通过显式映射迁移，并保留原标签。80 条保留集单独管理、复核，不能混入 300 条开发候选。

任务多时优先分发 A/S/M/C；之后安排新的 agent 做 B，再安排不同于生成者的 agent 做 R。H 适合交给未参与规则设计的 agent。不要在同一份已有生成历史中要求“盲标”。

## 产物及流转

每个任务只写 `.ai/intent-corpus-v1/<批次>/`，不得修改原语料、SPEC、程序、前端、Android、LM 或已有报告。本包不创建这些产物；各 agent 执行时创建自己的目录。重复运行使用新目录，例如 `S-run2`，禁止覆盖他人或先前结果。

生成批次交付：

- `candidates.jsonl`：完整输入、语义期望和依据，状态始终为候选。
- `inputs.jsonl`：只保留 id/message/history/display_action/clock，供独立标注；不含 family_id、标签、原因和笔记。
- `manifest.json`：契约版本、批次、条数、组数、内容哈希及覆盖统计。
- `summary.md`：已覆盖、未覆盖、疑难项、合成来源说明。

盲标输出单独的 `labels.jsonl`。裁决输出 `adjudication.jsonl`、`confirmed-candidates.jsonl`、`open-questions.md`，不就地改写原始候选。

确认过程不调用现有快路径来判断“期望是否正确”。实现结果与语义标签的差异另由后端工程师评估，允许暴露 GAP。程序测试通过不是自动入选条件，两个模型标注一致也不等于已得到人工黄金标签。

## 分组、保留集与规模

首轮 300+80 是建议试验规模，不代表已充分覆盖。先看分类争议和槽位标注质量，再决定下一批数量。不要规定接管率必须达到某个比例。

`family_id` 表示同一生成模板或语义骨架，而非 schedule/ticket 这类顶层类别；`contrast_group` 表示只变一个关键因素的对照组。同组样本不能拆到开发集和保留集。

R 对 S/M/C 全量检查模板近重复；H 的管理员再按语义骨架核对跨池近重复，重叠样本从保留集移除或补新骨架，并记录处理，不把重叠输入发给规则开发者用于补规则。H 在规则及分类版本冻结前，只发布覆盖统计和问题数量；输入与标签不给规则编写 agent 阅读。文件目录本身不提供权限隔离，需要分发者控制资料访问。

语料尚未复核和冻结之前，不用于报告“准确率提升”。评估同时检查任务保留、问题性质、完整关键槽位、来源及工具计划；不得只统计意图或快路径命中率。
