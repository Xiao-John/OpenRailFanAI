# v1.2：冻结编码后重新标注与复核

本文件由分发者给新的标注 agent；不授权自动创建或联系其他任务。先读 AGENTS.md、docs/ui-design-boundaries.md、docs/backend-parallel-development-boundaries.md。之后读本目录 CONTRACT.md、TASK-PROJECTION-v1.1.md、CODEBOOK-v1.2.md、codebook-v1.2.json、CALIBRATION-DECISIONS-v1.2.md。冲突以 v1.2 明确条款优先，其余待裁决项不得自行冻结。

分发者先指定角色和一个未使用的输出目录。建议两位独立标注者分别为 L12-A、L12-B，比较者为 L12-C；已有目录则增加运行后缀，只写自己的新目录。不改共同资料、原标签/报告、源码/测试、冻结语料、前端、Android、LM 或验收产物。不读 .env、密钥、私有日志或 H 保留集，不联网、不调用分类器或真实铁路工具。

## 角色一：独立重标

仅另外读取指定的 S/M/C inputs.jsonl（300 条），不读 L11-A/L11-B、旧生成标签或比较报告；不要从旧标签转换。原 14 条校准样本加 S-0046、M-0067、M-0080、C-0070 共 18 条按开发校准单列，其余 282 条也来自开发池，不宣称新的保留集/泛化证据。两位 agent 不互看标签。

逐条完成：

1. 按 operation+relation 分组。每个 query_unit 保留完整角色/日期绑定；OD、左右比较、到达/出发接续不按角色拆单元。共享车次或站点复制进各独立单元。
2. 使用机器编码表选择 requested_fields；具体结果不额外加泛指字段。空值/未知码不得用来回避标注。未能编码的内容原文进入 pending_fields，并标不可比维度。
3. time_basis 只用 scheduled/actual/mixed/unspecified/not_applicable；票务、配属、开行状态等不因需要检索就写 actual。口径、来源、查询日和是否缺对象分开。
4. 日期按本条 clock；不使用全局示例或机器日期。保存对象日期配对、具体钟点、窗口、来源。多个明确日期不是语义歧义；没有唯一车次也不妨碍解析明天。
5. 接续方向未知使用一个关系节点，未分配车次放 constraints.unassigned_trains；两个方向为 null。不得按提及顺序分配 G1 到达、G2 出发。
6. 多段行程、指代范围和依赖保留上下文。没有明确中转要求不派生 journey.transfer；票价/余票分任务，车型→线路/车次保持 emu.routing。未知线路不能默认第一段。
7. 最后计算兼容投影与策略。清楚的多对象与真正的未知对象分开；不得用 extra 藏诉求。事实检索任务多不等于 mixed，也不等于语义 resolved。

输出 labels-v1.2.jsonl：沿用 v1.1 主字段，contract_version="1.2"、codebook_version="1.2"；附 unit_sources、pending_fields，保留各任务 fact_basis。另输出 summary.md、validation.json，包含输入/编码表 SHA-256、ID/行数/组数/单元数、枚举违规、空字段违规、单角色拆分、来源/时间问题、仍未决内容。涉及行程引用的扩展结构明确说明并保留证据，不假称整个结构已冻结。

必须全量标注/检查 300 条，不能只修原 50 条分裂或只复制 A。先交付校准记录及全量自查；校验失败时修正自己的新产物，再交付。无法确定的语义保留 pending，不为了达成一致随意挑一个解释。

## 角色二：校验与比较

分发者指定两份 v1.2 标签后，才只读它们、对应输入和上述契约；不读 H。首先独立验证两侧编码表哈希相同、ID 覆盖、枚举、空字段、角色关系、日期与证据。输出 contract_violations.jsonl；违规不从分母删除、不经自动补值变成合规，严重影响可比性时暂停整体 L2 结论并列明原因。

不把一侧当正确答案。对齐完整关系节点，忽略独立单元顺序、字段数组顺序及重复；不能忽略方向、对象日期配对、段序、角色来源和实质筛选。不得用旧报告经验等价表。旧码仅在核对原文满足机器表条件时提出迁移记录；比较者不覆盖标签。

分层输出 comparison.md、agreement.json、open-questions.md：任务组；完整绑定+日期；字段；口径；限制条件；完整单元多重集方向匹配比例与对称 F1；投影；策略。自由说明只审计不做字符串相等准确率。约定未冻结部分的可比覆盖、未决项及全量分母都明确列出，不能把忽略绑定关系的任务内容集合当语义准确率。

裁决输出另存 adjudication-proposal.jsonl，区分表示迁移、契约违规、判断改正、未决；仅作为提案，不生成或冻结黄金集。开发校准 18 条与其余 282 条分开报；重标后一致率提高不等于当前系统准确率提高。
