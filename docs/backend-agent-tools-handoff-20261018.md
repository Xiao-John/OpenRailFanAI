# 对话操作与文件工具交接（2026-10-18）

本轮在 Main Android 与保留的 WebUI 中接入对话主题操作、文本文件导入和文件草稿导出。复用现有主题设置、聊天输入框及系统文件选择器；未调整页面布局。此任务由用户明确授权修改客户端必要接线，未扩展到 LM/iOS。

## 使用方法

| 输入示例 | 行为 |
|---|---|
| 切换到深色模式 / 请把主题改成浅色 | 立即修改并保存本机主题，无模型调用 |
| 主题跟随系统 | 恢复系统主题跟随 |
| 撤销刚才的主题切换 | 撤销本次运行期间最近一次对话主题操作，仅一级 |
| 导入文件 | 打开系统文件选择器，选好后填入可编辑处理草稿 |
| 请将已导入文件整理成 CSV 表格 | 发送附件给当前模型，返回 CSV 文件草稿 |
| 把上面的查询结果导出为 Markdown 表格 | 用最近对话内容生成文件，不再次查询铁路数据 |
| 把这段行程生成日历文件 | 日期、起止时间、时区明确时生成 ICS 草稿；缺失时询问 |
| 移除附件 | 清除当前会话尚未处理的附件 |

“如何开启深色模式”“不要切换深色模式”等问题、否定句及引号中的文本不会触发主题操作。模型回复和上传文件中的内容也不会执行主题操作。

文件导入后仍需用户发送处理要求，文件内容才会发给当前配置的模型。当前客户端每个会话保留一个待处理附件，内存保存，重启即清除；成功处理后移除，失败时保留以便重试。后续需要再次处理原文件时重新导入。生成文件不作为可重新下载的聊天附件持久化。

Android 使用系统“创建文档”界面选择保存位置；WebUI 发起浏览器下载。系统/浏览器的保存操作由用户完成。ICS 只是文件，不会自动写入日历，也不表示行程已确认或已购票。

## 文件范围

- 输入：UTF-8（可带 BOM）的 TXT、MD、CSV、JSON；单文件不超过 1 MiB / 60000 字符。JSON 需语法有效。
- 输出：表格 CSV/MD/JSON，文档 MD/JSON，日历 ICS；每次最多一个文件且不超过 1 MiB。
- 表格上限 32 列、500 数据行；日历上限 100 个事件。超限拒绝导出，不静默截断。CSV 对可能执行公式的单元格加文本前缀。
- 日历要求明确的带时区起止时间，结束晚于开始；导出 UTC，标注 `STATUS:TENTATIVE`，按 ICS 规则转义和折行。
- 本轮没有 PDF/Word/Excel 二进制读取、OCR、任意路径访问、脚本执行、联网资料抓取或系统日历写入。这里的工具链为“读取上传文本 → 模型整理 → 校验 → 确定性文件生成”。

## 后端契约与 Prompt

Main 新增 `POST /api/agent/run`，与铁路 `/api/chat`、`/api/chat/stream` 分开。普通铁路查询及原有 SSE 事件保持原契约。客户端仅对明确的文件请求或带待处理附件的请求调用新接口。

请求继承现有 BYOK 字段，并增加：

```json
{
  "message": "整理成CSV表格",
  "history": [],
  "actions": ["files"],
  "files": [{"name": "input.csv", "content_base64": "…"}]
}
```

`history` 最多20条，接口 `files` 最多2份，文件与历史合计最多80000字符。接口支持多份不表示当前选择器支持一次选多份。文件名不得包含路径分隔符；后端仅处理请求中的文本，不读取用户提供的本机路径。

两端仅在文件请求中把历史助手消息的 `displayResults` 与 `sources` 附入参考文本，让无正文的结构化卡片也可导出；普通铁路查询的历史格式保持原状。历史超出上下文或大小限制时需要缩小范围，不承诺自动导出整个会话。

成功返回 `handled/answer/files/usage`。文件字段为 `name/mime/content_base64`，名称固定为 `railfan-draft.<格式>`；没有文件时 `files=[]`。非文件请求返回 `handled=false`；参数/内容/方案无效为422，模型不可用为503。主题动作仅返回提案，需声明 `actions:["theme"]`；后端不会改变客户端设置。两端主题操作实际在本地完成。

专用 Prompt 位于 `backend/app/agent.py:SYSTEM_PROMPT`，已明确工具能力、文件/历史的数据身份、缺失信息询问、禁止编造铁路事实及“草稿≠已保存/已导入”的边界。固定提示和 schema 在前，变化的用户输入、文件与历史放在 `prompt_tail`。模型输出经过格式、大小、时间和截断检查后才能导出；生成文件时的回复由程序固定，不采用模型自述“已保存”。模型 token 用量沿用现有请求级统计，返回两端，不与铁路查询用量混用。

普通问答 Prompt（`backend/app/pipeline/generate.py`）也补充了这些操作入口及不得凭文字声称执行的约束，仅 Main 生效；不相关问题不主动介绍功能。
